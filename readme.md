# Expense Tracker

## About the Project
Expense Tracker is a simple web application created using HTML, CSS and JavaScript. It helps users manage their daily expenses by adding expenses with a title, amount, category and date.

## Features
- Add new expenses
- Edit existing expenses
- Delete expenses
- View total spending and transaction count
- Filter expenses by category and month
- Sort expenses by date and amount
- View spending by category using a chart
- Dark mode
- Save expenses using LocalStorage
- Responsive design for different screen sizes

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Files
- `index.html` – Structure of the website
- `style.css` – Styling and layout
- `script.js` – Functionality and expense management

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Add and manage your expenses.

## Data Storage
The application uses LocalStorage to save expenses and the selected theme in the browser. The saved data remains available after refreshing the page in the same browser.

## Learning Outcomes
Through this project, I practised HTML, CSS, JavaScript, DOM manipulation, event handling, arrays, objects, filtering, sorting and LocalStorage.

## Conclusion
Expense Tracker provides a simple way to manage daily expenses through a web browser. This project helped me understand how to create an interactive web application using HTML, CSS and JavaScript.
